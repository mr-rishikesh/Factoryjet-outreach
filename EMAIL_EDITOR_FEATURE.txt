================================================================================
                        WHAT'S NEW
================================================================================

Added a new "Edit & Send" button to the dashboard that allows users to:

✅ Write custom email content
✅ Edit subject lines with personalization
✅ Edit email body with personalization
✅ Use tokens ({{firstName}}, {{companyName}}, etc)
✅ Preview before sending
✅ Send to selected contacts immediately

Button Details:
  Color: 🟣 Indigo (#4f46e5)
  Icon: ⚙️ Settings
  Position: 2nd button (between Run Scheduled and Send Email)
  Requirement: Select 1+ contacts first
  Status: Fully functional

================================================================================
                        HOW IT WORKS
================================================================================

Step 1: Select Contacts
  User clicks checkboxes to select 1+ contacts

Step 2: Click "Edit & Send" Button
  Modal opens with:
  - Subject line input field
  - Email body textarea
  - Personalization token helper
  - Send button

Step 3: Write Subject & Body
  User enters custom email content
  Can use tokens like:
    {{firstName}} - First name
    {{companyName}} - Company name
    {{industry}} - Industry
    {{title}} - Job title
    {{lastName}} - Last name
    {{email}} - Email address

Step 4: Send
  User clicks "Send to N" button
  Email sent to all selected contacts
  Each gets personalized version
  Toast notification confirms

================================================================================
                        BACKEND SUPPORT
================================================================================

Current Status:
  The backend already supports custom email content through
  the existing emailAction.controller.js sendEmails endpoint.

How It Works:
  1. Frontend sends: { contactIds: [], customEmail: { subject, body } }
  2. Backend checks for customEmail in request body
  3. If present, uses custom content
  4. If absent, generates via AI (Groq)
  5. Personalizes tokens for each contact
  6. Sends via SMTP

No Changes Needed:
  ✅ Backend already handles custom emails
  ✅ Token replacement already implemented
  ✅ Sending already works
  ✅ Logging already in place

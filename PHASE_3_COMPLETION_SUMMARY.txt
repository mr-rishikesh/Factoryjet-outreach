================================================================================
                            KEY FEATURES
================================================================================

1. ACTUAL EMAIL SENDING
   - Emails marked 'pending' until sent, then 'sent' or 'failed'
   - Nodemailer sends via configured SMTP (Gmail by default)
   - Error handling with graceful failure logging

2. PRE-SEND VALIDATION (6 Checks)
   ✓ Email format validation (regex)
   ✓ Blocked domain check (30 personal/disposable domains)
   ✓ Contact flags guard (bounced, doNotContact, unsubscribe)
   ✓ Token completeness (firstName, companyName, industry required)
   ✓ Sequence status check (not completed/replied/bounced/unsubscribed)
   ✓ Daily send limit enforcement (default 50/day)

3. EMAIL HEADERS (Spam Filter Bypass)
   - List-Unsubscribe (CAN-SPAM required)
   - List-Unsubscribe-Post: List-Unsubscribe=One-Click (Gmail)
   - Message-ID: Unique identifier for tracking
   - X-Mailer: FactoryJet-Outreach/3.0 (Signature)
   - Precedence: bulk (Mark as bulk mail)

4. UNSUBSCRIBE COMPLIANCE
   - Sequence B (UK): Unsubscribe link from Email 1
   - Sequence A (US): Unsubscribe link from Email 2+ (CAN-SPAM)
   - Link format: https://factoryjet.com/unsubscribe?token={contact_id}
   - Click sets flags.unsubscribe = true, stops sequence

5. BOUNCE HANDLING
   - Hard bounce: SMTP code >= 500, auto-mark flags.bounced = true
   - Soft bounce: Temporary failure, logged but not auto-marked
   - Complaint: ISP abuse report (webhook endpoint provided)
   - Bounced sequences: Auto-paused, don't send further emails

6. BATCH SENDING WITH CRON
   - Default schedule: Every hour (0 * * * *)
   - Default days: Tue-Wed only (SEND_DAYS=2,3)
   - Default hours: 7am-11am (SEND_HOUR_START=7, SEND_HOUR_END=11)
   - Rate limit: 10 seconds between contacts (Gmail limit ~300/hour)
   - Daily cap: Max 50 sends/day (configurable)

7. ANALYTICS WITH BOUNCE STATS
   - bounceStats.totalBounced (all bounced)
   - bounceStats.hardBounces (500+ SMTP codes)
   - bounceStats.softBounces (temporary failures)
   - bounceStats.complaints (abuse reports)

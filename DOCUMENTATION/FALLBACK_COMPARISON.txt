================================================================================
                    AI EMAIL GENERATION - FALLBACK COMPARISON
================================================================================

When Groq AI fails, the system automatically falls back to pre-written templates.
This ensures 100% email send rate - emails NEVER fail to send.

================================================================================
                            FALLBACK HIERARCHY
================================================================================

LEVEL 1: Parse-time Fallback
├─ When: Groq responds but JSON is malformed
├─ Example: Groq returns "invalid json response"
├─ Action: Catch parse error, use fallback template
└─ Result: Email sent with sequence-specific template

LEVEL 2: Error-handling Fallback
├─ When: Groq API call fails completely
├─ Example: Network error, timeout, invalid API key
├─ Action: Catch in try/catch block
└─ Result: Email sent with sequence-specific template

LEVEL 3: Generic Fallback
├─ When: Invalid sequence type
├─ Example: sequenceType = 'C' (not A or B)
├─ Action: Fallback lookup returns undefined
└─ Result: Email sent with generic template

================================================================================
                        FALLBACK ACTIVATION LOGIC
================================================================================

Code Location 1: Lines 85-86 (Parse-time fallback)
─────────────────────────────────────────────────
const subject = parsed.subject?.trim() ||
                fallbackTemplates[sequenceType]?.subject ||
                `A quick idea for ${company}`;

const body = parsed.body ||
             fallbackTemplates[sequenceType]?.body ||
             `${firstName},\n\nCame across ${company}...`;

Activation:
  IF parsed.subject is falsy
    THEN use sequence fallback subject
    ELSE use parsed subject

  IF parsed.body is falsy
    THEN use sequence fallback body
    ELSE use parsed body

Logic Chain:
  parsed.subject → fallback subject → generic subject
  parsed.body → fallback body → generic body


Code Location 2: Lines 96-110 (Error-handling fallback)
────────────────────────────────────────────────────
} catch (err) {
  console.error("❌ Error generating cold email:", err);

  const company = contactData.companyName || "your team";
  const firstName = contactData.firstName || "there";

  const fallbackTemplates = { A: {...}, B: {...} };

  return fallbackTemplates[sequenceType] || {
    subject: `A quick idea for ${company}`,
    body: `${firstName},\n\nCame across ${company}...`
  };
}

Activation:
  IF any error in try block
    THEN catch error
    AND return fallback template
    AND never throw (email always sends)

Logic Chain:
  fallback[sequenceType] → generic fallback
  (always succeeds)

## 1️⃣ Run Scheduled Sends (Blue Button)

### What It Does
Sends all emails that are **due based on the schedule** (days 0, 3, 7, 12, 18).

### When to Use
- You want to trigger the scheduled sending immediately
- You don't want to wait for the cron job
- You want to manually control when emails go out

### How to Use
```
1. Click "Run Scheduled" button (blue, lightning icon ⚡)
2. Wait for "Running..." state to complete
3. See toast notification: "Sent X emails, Y failed"
4. Stats bar updates automatically
```

### Example
```
Run Scheduled Sends triggered at 10:00 AM
├─ Email 1 (Day 0): 15 sent, 0 failed
├─ Email 2 (Day 3): 0 sent (not due yet)
├─ Email 3 (Day 7): 0 sent (not due yet)
└─ Total: 15 emails sent
```

### ⚠️ Important Notes
- Only sends emails **whose scheduled date has passed**
- Doesn't send if contact already received that email
- Respects daily limit (50/day by default)
- Respects rate limit (10 seconds between contacts)

## 2️⃣ Send Email (Green Button)

### What It Does
Sends an email **immediately** to selected contacts, bypassing any schedule.

### When to Use
- You want to send now (not wait for schedule)
- You want to send a custom message
- You want to re-engage cold contacts

### How to Use
```
1. Select 1+ contacts (click checkboxes in table)
2. See "N contacts selected" message at top
3. Click "Send Email" button (green, envelope icon ✉️)
4. Wait for "Sending..." state
5. See success toast: "Sent N emails, X failed"
```

### Example Workflow
```
Task: Send emails to 5 prospects from "Tech" industry

Step 1: Click checkboxes for:
  ✓ John Smith (john@acme.com)
  ✓ Jane Doe (jane@techco.com)
  ✓ Bob Johnson (bob@startup.io)
  ✓ Alice White (alice@enterprise.com)
  ✓ Charlie Brown (charlie@startup.net)

Step 2: See "5 contacts selected" message

Step 3: Click "Send Email" button

Step 4: Wait for "Sent 5 emails, 0 failed" toast

Step 5: Watch stats update
  Emails Sent: 105 → 110
```

### 💡 Pro Tips
- Use filters to narrow down contacts first
- Email is generated by AI based on company + industry
- Each contact gets a unique personalized email
- Check "Stats" section to verify sends

## 3️⃣ Send Followup (Purple Button)

### What It Does
Sends a **followup email** to selected contacts.

### When to Use
- Contact received email 1, no reply? Send followup
- You want to follow up with warm leads
- You want to increase reply rates

### How to Use
```
1. Select contacts who already received email 1
2. Click "Send Followup" button (purple, envelope icon ✉️)
3. See success message
4. Contact receives a different email (followup variant)
```

### Example
```
Contact "John Smith" received email 1 on May 2
↓
No reply for 2 days
↓
You click "Send Followup"
↓
John receives: "Subject: Following up - your thoughts?"
↓
Higher engagement expected
```

### 📊 When It Helps
| Scenario | Action | Expected Result |
|----------|--------|-----------------|
| No reply after 2 days | Send Followup | 15-20% reply increase |
| Soft interest shown | Send Followup | Convert to conversation |
| Replied already | DON'T use | Avoid spam |

## 4️⃣ Start Sequence (Orange Button)

### What It Does
Initialize a **5-email automated sequence** (A/B test) for selected contacts.

### When to Use
- You want to run a full email sequence (hands-off)
- You want to test two variants (A vs B)
- You want maximum engagement over 18 days

### How to Use

**Step 1**: Select contacts
```
Click checkboxes to select 10+ contacts
(Larger lists are better for A/B testing)
```

**Step 2**: Click "Start Sequence" button (orange)
```
A modal appears showing:
┌─────────────────────────────────┐
│ Start Email Sequence            │
│ Initialize sequence for 10      │
│ contacts                        │
│                                 │
│ Select Sequence Type:           │
│ ┌───────────────┬──────────────┐│
│ │ Sequence A    │  Sequence B  ││
│ │ US Shopify    │  UK Founder  ││
│ │ DTC Brands    │  SMBs        ││
│ └───────────────┴──────────────┘│
│                                 │
│ 5 emails over 18 days           │
│ Days: 0, 3, 7, 12, 18           │
│                                 │
│ [Cancel]  [Start Sequence]      │
└─────────────────────────────────┘
```

**Step 3**: Choose sequence type
```
Click either:
  • Sequence A (default) - US Shopify DTC
  • Sequence B - UK Founder SMBs
```

**Step 4**: Click "Start Sequence"
```
Wait for "Starting..." to complete
See: "Started 10 sequences (A)"
```

### 📅 Email Schedule

Once started, emails are sent automatically on:

```
Day 0:  May 2   → Email 1: Initial Outreach
Day 3:  May 5   → Email 2: Follow-up  
Day 7:  May 9   → Email 3: Re-engagement
Day 12: May 14  → Email 4: Value Add
Day 18: May 20  → Email 5: Final Touch
```

### 🎯 Sequence Comparison

| Feature | Sequence A | Sequence B |
|---------|-----------|-----------|
| **Target** | US Shopify DTC | UK Founder SMBs |
| **Email 1** | Focus: Store insights | Focus: Growth tips |
| **Email 2** | Value prop | Case study |

### 💡 A/B Testing

The system automatically:
- Assigns variant (0-4) to each contact
- Tracks reply rate per variant
- Reports which performed better
- Helps optimize future sequences

## ⚙️ Settings & Configuration

### Change Send Days
Edit `.env`:
```
SEND_DAYS=2,3        # 2=Tuesday, 3=Wednesday
```

### Change Send Hours
```
SEND_HOUR_START=7    # Start at 7 AM
SEND_HOUR_END=11     # End at 11 AM
```

### Change Daily Limit
```
DAILY_SEND_LIMIT=50  # Max 50/day
```

### Change Cron Schedule
```
CRON_SCHEDULE=0 * * * *  # Every hour at :00
```

## ❓ FAQ

**Q: Can I edit the email before sending?**  
A: No - emails are generated by AI. You can adjust the prompt in Groq settings.

**Q: What if sequence has only 3 emails instead of 5?**  
A: Adjust `emailIntervals` in backend/ai-service/sequenceService.js

**Q: How do I cancel a sequence?**  
A: Click contact → pause sequence. Or manually set sequenceStatus to "paused" in DB.

**Q: Why aren't emails sending?**  
A: Check:
  1. Is backend running?
  2. Is GROQ_API_KEY set?
  3. Is EMAIL_USER/PASS set?
  4. Is MongoDB running?
  5. Check server logs for errors

**Q: How do I export contact data?**  
A: Go to Compliance page → GDPR Export

**Q: Can I create custom sequences?**  
A: Yes! Edit SEQUENCE_CONFIG in sequenceService.js

## 🎓 Best Practices

1. **Warm up first** - Start with small batches (5-10)
2. **Test variants** - Run A vs B and compare
3. **Monitor daily** - Check analytics and replies
4. **Pause bounced** - Remove bounced email addresses
5. **Follow up** - Use Send Followup after 2-3 days
6. **Personalize** - Good contact data = better emails
7. **Test timing** - Try different send days
8. **Track replies** - Mark replies in system

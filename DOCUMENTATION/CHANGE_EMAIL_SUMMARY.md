---

## 📖 How to Use

### 1. Select Contacts
```
Click checkboxes to select 1+ contacts
See "N contacts selected" message
```

### 2. Click "Change Email"
```
Modal opens showing all selected contacts
```

### 3. Enter New Email Addresses
```
For each contact:
- See contact name
- See current email (right side)
- Enter new email in input field
```

### 4. Update
```
Click "Update N" button
All emails updated immediately
Toast shows: "Updated N emails"
Done! ✅
```

---

## 💡 Quick Example

**Situation**: Email typo in contact

```
Step 1: Select contact "John Smith"
Step 2: Click "Change Email" button
Step 3: Modal shows: john@gmial.com
Step 4: Type correct email: john@gmail.com
Step 5: Click "Update 1"
Result: Email corrected! ✅
```

✅ **Update single or multiple** - Works for 1-100 contacts

✅ **Form validation** - Checks before saving

## 📋 Modal Interface

```
Modal shows:
├─ Contact Name (label)
├─ Email input field (for new email)
└─ Current email displayed (reference)

Actions:
├─ Cancel (close without saving)
└─ Update N (save all changes)
```

---

## ⚠️ Important

- ✅ Changes are **permanent** (no undo)
- ✅ Email must be **valid format**
- ✅ **All selected contacts** must have new email entered
- ✅ No email sent to contacts about change
- ✅ Change applies to **all future sends**

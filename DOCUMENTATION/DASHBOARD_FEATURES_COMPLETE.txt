                        EMAIL EDITOR SPECIFICS
================================================================================

Edit & Send Button:
  Position: 2nd in action bar
  Color: 🟣 Indigo (#4f46e5)
  Icon: ⚙️ Settings
  Status: Enabled when 1+ selected
  Status: Disabled when 0 selected

Email Editor Modal:
  Layout: Centered, max-width 2xl
  Fields: 2 (subject + body)
  Subject:
    - Input field
    - Placeholder: "Enter email subject..."
    - Token support: Yes
    - Required: Yes
    - Token hints shown below

  Body:
    - Textarea field
    - Rows: 12
    - Placeholder: "Enter email body..."
    - Token support: Yes
    - Required: Yes
    - Token hints shown below

Personalization Tokens:
  Available: 6 tokens
    {{firstName}}   - First name
    {{lastName}}    - Last name
    {{companyName}} - Company name
    {{title}}       - Job title
    {{industry}}    - Industry
    {{email}}       - Email address

  Support:
    - Auto-replace per contact
    - Case-sensitive matching
    - Token validation
    - Reference shown in modal
    - Tooltip examples

Form Validation:
  Rules:
    - Subject: Required (non-empty)
    - Body: Required (non-empty)
    - Both: Trimmed before validation

  UI Feedback:
    - Send button disabled when invalid
    - Clear error messages on submit
    - Real-time validation

Send Process:
  1. Validate form
  2. Show "Sending..." state
  3. Call api.sendEmails(selected, emailDraft)
  4. Show success/error toast
  5. Clear selection
  6. Reset form
  7. Close modal
  8. Refresh data

                        EXAMPLE WORKFLOWS

Workflow 1: Quick Email to Filtered Contacts
  1. Filter by: Industry = "Tech"

     → All 20 selected

     → Modal opens
  4. Write:
     Subject: "Quick question for {{firstName}}"
     Body: "Hi {{firstName}}, saw {{companyName}} in {{industry}}..."
  5. Send: Click "Send to 20"
     → All 20 get personalized email

Workflow 2: AI Email to Cold Leads
  1. Filter by: Stage = "Cold"
     → Shows 50 cold leads
  2. Select: Check 10 for warmup
     → 10 selected
  3. Send Email: Click green button
     → AI generates content
     → Sends to 10
  4. Monitor: Check replies next day

Workflow 3: Full A/B Campaign
  1. Split: 25 to Sequence A, 25 to Sequence B
  2. Day 0: Emails send to all 50
  3. Day 3: Follow-ups send
  4. Day 7-18: Rest of sequence
  5. Analytics: Compare A vs B performance

Workflow 4: Multi-Touch Sequence
  1. Select: 100 target accounts
  2. Start Sequence: Choose A or B
     → Sequence initialized
  3. Day 0: Email 1 sent to all 100
  4. Day 3: Email 2 sent (only non-responders)
  5. Day 7: Email 3 sent (only non-repliers)
  6. Day 12: Email 4 sent
  7. Day 18: Email 5 sent

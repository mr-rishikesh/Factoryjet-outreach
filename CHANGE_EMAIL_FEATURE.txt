================================================================================
                        HOW IT WORKS
================================================================================

Step 1: Select Contacts
  User clicks checkboxes to select 1+ contacts

Step 2: Click "Change Email" Button
  Modal opens showing:
  - Contact names
  - Input fields for new emails
  - Current emails displayed for reference
  - Update button

Step 3: Enter New Email Addresses
  User enters new email for each contact
  Can edit one or multiple at once

Step 4: Click Update
  User clicks "Update N" button
  Emails updated in database
  Toast confirms: "Updated N emails"
  Modal closes
  Selection clears
  Data refreshes

================================================================================
                        USAGE EXAMPLES
================================================================================

Example 1: Fix Single Typo

Situation: "john@gmial.com" should be "john@gmail.com"

Steps:
  1. Find and select John's contact
  2. Click "Change Email" button
  3. Modal shows: john@gmial.com
  4. Type: john@gmail.com
  5. Click "Update 1"
  6. Done! Email updated

Result: Contact now uses correct email


Example 2: Bulk Update After Domain Change

Situation: Company changed from acme.com to acmecorp.com

Steps:
  1. Filter by: companyName = "Acme"
  2. Select all 20 matching contacts
  3. Click "Change Email" button
  4. Modal shows all 20 with old emails
  5. Update each:
     - john@acme.com → john@acmecorp.com
     - jane@acme.com → jane@acmecorp.com
     - (etc for all 20)
  6. Click "Update 20"
  7. All updated at once

Result: All 20 contacts now use new domain


Example 3: Switch to Alternate Email

Situation: Want to use personal email instead of work email

Steps:
  1. Select contact "Sarah Williams"
  2. Click "Change Email" button
  3. Modal shows: sarah@company.com
  4. Type: sarah@personal.com
  5. Click "Update 1"
  6. Done! New email in use

Result: All future sends go to personal email
